Build Process Watcher

GitHub Action and browser dashboard for monitoring GradleDaemon, GradleWorkerMain, and KotlinCompileDaemon heap, RSS, GC time, JIT compilation, class loading, and VM flags, without injecting a Java agent.

Export artifacts locally (JSON, CSV, SVGs, job summary) or stream live runs with 24-hour retention.

Local Mode: GitHub Actions summary & artifacts

With no backend enabled, the action writes a Mermaid checkpoint flow and per-process stats table directly to the job summary, and saves build_process_watcher.json, CSV, and SVG charts as workflow artifacts.

Local Mode snippet

Quick start

Unreleased development ref: snippets pin 88f0d0b for planned v0.8.0 (unreleased) inputs. Published v0.7.0 does not accept prediction_mode or prediction_throttle_s (release notes).

Local Mode · artifacts only

Logs, JSON, CSV, SVG charts, and job summary in workflow artifacts. Nothing leaves GitHub Actions.

- name: Build Process Watcher
  uses: cdsap/build-process-watcher@88f0d0b85857dd71009cf827564fb33d75769214

- name: Build project
  run: ./gradlew clean build

Remote Mode · live dashboard

Streams samples live, prints a run URL, and retains the hosted report for 24 hours.

- name: Build Process Watcher
  uses: cdsap/build-process-watcher@88f0d0b85857dd71009cf827564fb33d75769214
  with:
    remote_monitoring: 'true'

- name: Build project
  run: ./gradlew clean build

BigQuery export · optional

Requires Remote Mode and a backend configured with BIGQUERY_EXPORT_DATASET.

- name: Build Process Watcher
  uses: cdsap/build-process-watcher@88f0d0b85857dd71009cf827564fb33d75769214
  with:
    remote_monitoring: 'true'
    export_to_bigquery: 'true'

- name: Build project
  run: ./gradlew clean build

Timeline prediction (Experimental)

Opt-in forecasts. Choose a prediction mode or add prediction_target: 'class_loading'.

- name: Build Process Watcher
  uses: cdsap/build-process-watcher@88f0d0b85857dd71009cf827564fb33d75769214
  with:
    prediction_mode: 'predict'
    prediction_throttle_s: '20'

- name: Build project
  run: ./gradlew clean build

Timeline prediction modes

Experimental and disabled by default. Active modes automatically enable Remote Mode. Prediction does not enable export_to_bigquery; enable BigQuery export separately when needed. A selected mode reports a request, not provider availability or successful inference.

TabPFN is disabled by default; available only when its VM/provider is available. Selecting the input does not start the VM or guarantee forecasts.

Prediction is an opt-in advisory signal for triage, not a guaranteed OOM, timeout, or build-failure outcome. Do not use it as a production decision or reliability guarantee.

Memory forecasts (+10 / +30 / +60s)

Experimental

Per-process Heap and RSS forecast overlays with Latest, Last 3, and All issuance replay controls.

Class-loading forecasts (+60s)

Contract

Set prediction_target: class_loading with predict, forecast, or tabpfn for +60s class-count deltas.
