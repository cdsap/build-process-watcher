Quick start

Add to GitHub Actions

Unreleased development ref: snippets below pin 88f0d0b for planned v0.8.0 (unreleased) inputs. Published v0.7.0 does not support prediction_mode or prediction_throttle_s. See release notes.

Local Mode · artifacts only

Writes JSON, CSV, SVG charts, and the Actions summary as workflow artifacts. Nothing is sent to the hosted dashboard.

- name: Build Process Watcher
  uses: cdsap/build-process-watcher@88f0d0b85857dd71009cf827564fb33d75769214

- name: Build project
  run: ./gradlew clean build

Remote Mode · live dashboard

Streams samples live, prints a dashboard URL, and retains the hosted report for 24 hours.

- name: Build Process Watcher
  uses: cdsap/build-process-watcher@88f0d0b85857dd71009cf827564fb33d75769214
  with:
    remote_monitoring: 'true'

- name: Build project
  run: ./gradlew clean build

BigQuery export · optional

Independent export choice requiring Remote Mode and a backend configured with BIGQUERY_EXPORT_DATASET.

- name: Build Process Watcher
  uses: cdsap/build-process-watcher@88f0d0b85857dd71009cf827564fb33d75769214
  with:
    remote_monitoring: 'true'
    export_to_bigquery: 'true'

- name: Build project
  run: ./gradlew clean build

Timeline prediction · Experimental

Opt-in per-process forecasts. Add prediction_target: 'class_loading' for +60s class-loading activity.

- name: Build Process Watcher
  uses: cdsap/build-process-watcher@88f0d0b85857dd71009cf827564fb33d75769214
  with:
    prediction_mode: 'predict'
    prediction_throttle_s: '20'

- name: Build project
  run: ./gradlew clean build
Experimental prediction

Timeline prediction modes

Prediction is disabled by default. Active modes automatically enable Remote Mode. Prediction does not enable export_to_bigquery; enable BigQuery export separately when needed. A selected mode reports a request, not provider availability or successful inference.

TabPFN is disabled by default; available only when its VM/provider is available. Selecting the input does not start the VM or guarantee forecasts.

Advisory only: prediction is an opt-in advisory signal for triage, not a guaranteed OOM, timeout, or build-failure outcome. Do not use it as a production decision or reliability guarantee.
prediction_mode Model / behavior Availability
disabled / omittedNo prediction requestDefault; local monitoring remains possible.
forecastTimesFM time-series forecastsRequires the configured hosted provider.
predictTabFM tabular prediction; distinct from TabPFNRequires the configured hosted provider.
bqml-boostedTrained BigQuery ML boosted-tree forecastsRequires the configured trained-model provider (memory only).
tabpfnTabPFN GPU inference on a VMDisabled by default; requires an available VM/provider. Does not start the VM.
